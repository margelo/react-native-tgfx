Every drawing is a child of [`Canvas`](/api/functions/Canvas) — or, without
React, a node built by the matching lowercase element factory and held in a
[`Scene`](/api/classes/Scene). Both forms compile to the identical program:

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
import { Canvas, Rect } from 'react-native-tgfx'

<Canvas style={{ width: 300, height: 140 }}>
  <Rect x={0} y={0} width={300} height={140} color="#101725" />
</Canvas>
```

</Tab>
<Tab value="Imperative">

```ts
import { Scene, rect } from 'react-native-tgfx'

const scene = Scene.create()
scene.add(rect({ x: 0, y: 0, width: 300, height: 140, color: '#101725' }))
scene.attach(viewRef) // a TgfxViewRef from <TgfxNativeView>
```

</Tab>
</Tabs>

Every component in the tables below has a factory of the same name in
lowercase (`Rect` → `rect`, `LinearGradient` → `linearGradient`, ...), taking
the same props plus an optional children array — see
[Imperative](/docs/imperative).

## Paint

Props inline, or a [`Paint`](/api/variables/Paint) child ([`PaintProps`](/api/interfaces/PaintProps)):

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
<Circle cx={70} cy={70} r={40}>
  <Paint color="#f2c088" style="stroke" strokeWidth={3} />
</Circle>
```

</Tab>
<Tab value="Imperative">

```ts
scene.add(
  circle({ cx: 70, cy: 70, r: 40 }, [
    paint({ color: '#f2c088', style: 'stroke', strokeWidth: 3 }),
  ])

```

</Tab>
</Tabs>

[`Color`](/api/type-aliases/Color) accepts named colours, hex, `rgb()`/`rgba()`,
`hsl()`/`hsla()`, packed `0xAARRGGBB`, `[r, g, b, a]` in 0..1, and the
`color(srgb ...)` and `color(display-p3 ...)` forms:

<Tabs items={['Declarative', 'Imperative']}>

<Rect color="color(display-p3 1 0.2 0.1)" />
<Rect color="color(srgb 1 0 0 / 0.5)" />

</Tab>
<Tab value="Imperative">

## Group

[`GroupProps`](/api/interfaces/GroupProps). Paint and [`Transform`](/api/type-aliases/Transform) inherit down.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
<Group transform={[{ translate: [40, 0] }, { rotate: '12deg' }, { scale: 1.5 }]}>
  <Rect x={0} y={0} width={40} height={40} />
</Group>
```

```tsx
<Group clip={{ x: 0, y: 0, width: 100, height: 100, r: 12 }}>
  <TgfxImage x={0} y={0} width={100} height={100} image={photo} />
</Group>
```

</Tab>
<Tab value="Imperative">

```ts
scene.add(
  group({ transform: [{ translate: [40, 0] }, { rotate: '12deg' }, { scale: 1.5 }] }, [
    rect({ x: 0, y: 0, width: 40, height: 40 }),
  ])
)
```

```ts
scene.add(
  group({ clip: { x: 0, y: 0, width: 100, height: 100, r: 12 } }, [
    image({ x: 0, y: 0, width: 100, height: 100, image: photo }),
  ])
)
```

</Tab>
</Tabs>

`clip` takes a [`ClipRect`](/api/interfaces/ClipRect) or SVG path data;
`invertClip` keeps what falls *outside* it instead of inside. `origin` shifts
the pivot `transform` rotates and scales around, away from `(0, 0)`.

`layer` composites children into one offscreen layer first, so a group opacity
applies to the union rather than to each child:

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
<Group layer opacity={0.5}>
  <Circle cx={40} cy={40} r={30} color="#4F8EF7" />
  <Circle cx={70} cy={40} r={30} color="#4F8EF7" />
</Group>
```

</Tab>
<Tab value="Imperative">

```ts
scene.add(
  group({ layer: true, opacity: 0.5 }, [
    circle({ cx: 40, cy: 40, r: 30, color: '#4F8EF7' }),
    circle({ cx: 70, cy: 40, r: 30, color: '#4F8EF7' }),
  ])
)
```

</Tab>
</Tabs>

`picture` records children once and replays them — for static subtrees.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
<Group picture>
  <Path path={gridPath} color="#e5e5ea" style="stroke" />
</Group>
```

</Tab>
<Tab value="Imperative">

```ts
scene.add(
  group({ picture: true }, [
    path({ path: gridPath, color: '#e5e5ea', style: 'stroke' }),
  ])
)
```

</Tab>
</Tabs>

### 3D transforms

`transform` also takes `perspective`, `rotateX`, `rotateY` and `translateZ`.
Put `perspective` before the rotations it applies to. Every operand can be a shared value or be written
through a node handle; one the transform lacks is appended after the translation (`perspective`) or at
the end (everything else).

`preserve3d` places the child groups in one 3D space, so they hide one another
by depth. Without it, each child is flattened into the group's plane and drawn
in order. It needs a GPU surface: inside a `picture` group or an export, the
children are drawn flattened. As with CSS grouping properties, `clip`, `layer`,
`picture` or a `<FilmGrain>` on the group itself flatten it; on a child group
they apply to that child's plane. A `<Fill>` on a plane covers the plane's clip,
or else the area of the canvas. Hit tests compose the same 3D space and report
the nearest plane first.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
<Group
  preserve3d
  transform={[{ translate: [150, 150] }, { perspective: 900 }, { rotateY: turn }]}
>
  <Group transform={[{ translateZ: 50 }]}>
    <Rect x={-50} y={-50} width={100} height={100} color="#0a84ff" />
  </Group>
  <Group transform={[{ rotateY: '90deg' }, { translateZ: 50 }]}>
    <Rect x={-50} y={-50} width={100} height={100} color="#ff3b30" />
  </Group>
</Group>
```

</Tab>
<Tab value="Imperative">

```ts
scene.add(
  group(
    {
      preserve3d: true,
      transform: [{ translate: [150, 150] }, { perspective: 900 }, { rotateY: turn }],
    },
    [
      group({ transform: [{ translateZ: 50 }] }, [
        rect({ x: -50, y: -50, width: 100, height: 100, color: '#0a84ff' }),
      ]),
      group({ transform: [{ rotateY: '90deg' }, { translateZ: 50 }] }, [
        rect({ x: -50, y: -50, width: 100, height: 100, color: '#ff3b30' }),
      ]),
    ]
  )
)
```

</Tab>
</Tabs>

## Viewport

`<Canvas viewport={{ zoom, x, y }}>` is a zoom/pan the renderer applies above the
whole scene, so moving it never re-encodes the draw program.
[`CanvasHandle.setViewport`](/api/interfaces/CanvasHandle) is the imperative form
and the one a gesture should use — see
[Zoom and pan](/docs/animation#zoom-and-pan). `hitTest` inverts it, so the two
stay in agreement at any zoom. Headless, the same `[zoom, x, y]` triple goes to
[`surface.setViewport`](/docs/snapshots#retained-surface).

## Hit testing

[`CanvasHandle.hitTest`](/api/interfaces/CanvasHandle) returns [`HitTestResult`](/api/interfaces/HitTestResult) topmost first.

```tsx
const canvas = useRef<CanvasHandle>(null)
const bar = useNode()

<GestureDetector gesture={Gesture.Tap().onEnd((e) => {
  const hits = canvas.current?.hitTest(e.x, e.y) ?? []
  if (hits.some((hit) => hit.node === bar)) select(bar)
})}>
  <Canvas ref={canvas} style={{ flex: 1 }}>
    <Rect ref={bar} x={10} y={10} width={40} height={80} color="#0a84ff" />
  </Canvas>
</GestureDetector>
```

[`useCanvasPress`](/api/functions/useCanvasPress) wires the same thing to the responder system:

```tsx
const onTouch = useCanvasPress(canvas, [[bar, () => select(bar)]], {
  precise: true,
  onPress: ({ x, y, nodes }) => track(x, y, nodes),
})

<View onStartShouldSetResponder={() => true} onResponderRelease={onTouch}>
  <Canvas ref={canvas}>
    <Rect ref={bar} x={10} y={10} width={40} height={80} color="#0a84ff" />
  </Canvas>
</View>
```

Third argument is a [`CanvasPressOptions`](/api/interfaces/CanvasPressOptions):
`precise` tests the filled region rather than the bounding box, and `onPress`
gets a [`CanvasPress`](/api/interfaces/CanvasPress) for every press, whatever
it landed on — including nothing.

Headless, the same topmost-wins dispatch runs against an offscreen surface —
[`dispatchPress`](/api/functions/dispatchPress) plus `Scene.handlesAt`:

```ts
dispatchPress(scene.handlesAt(surface.hitTest(x, y, true)), [
  [bar, () => select(bar)],
])
```
