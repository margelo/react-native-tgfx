[`Shader`](/api/variables/Shader) accepts the SkSL subset supported by tgfx,
transpiles it while the scene is compiled, and creates the runtime shader
natively ([`ShaderProps`](/api/interfaces/ShaderProps)). `main` receives the
position in local space and returns a premultiplied `half4`.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
import { Canvas, Fill, Shader } from 'react-native-tgfx'

const source = `
uniform float2 uSize;
half4 main(float2 pos) {
  float2 uv = pos / uSize;
  return half4(uv.x, uv.y, 0.6, 1.0);
}
`

<Canvas style={{ width: 300, height: 140 }}>
  <Fill>
    <Shader source={source} uniforms={{ uSize: [300, 140] }} />
  </Fill>
</Canvas>
```

</Tab>
<Tab value="Imperative">

```ts
import { Scene, fill, shader } from 'react-native-tgfx'

const source = `
uniform float2 uSize;
half4 main(float2 pos) {
  float2 uv = pos / uSize;
  return half4(uv.x, uv.y, 0.6, 1.0);
}
`

const scene = Scene.create()
scene.add(
  fill({}, [
    shader({ source, uniforms: { uSize: [300, 140] } }),
  ])
)
```

</Tab>
</Tabs>

<Callout>
Declarations must come before `main()`, or compilation fails with
`[tgfx] shader: declarations must come before main(), found after it`.
</Callout>

## Animated uniforms

Uniform values accept a `SharedValue`, so they update on the UI thread.
[`useClock`](/api/functions/useClock) is a shared value of seconds since its
first frame callback.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const t = useClock()

<Fill>
  <Shader source={source} uniforms={{ uTime: t, uSize: [width, height] }} />
</Fill>
```

</Tab>
<Tab value="Imperative">

```ts
const clock = createClock()

scene.add(
  fill({}, [
    shader({ source, uniforms: { uTime: clock.value, uSize: [width, height] } }),
  ])
)
```

</Tab>
</Tabs>

## Shader inputs

Each `uniform shader` declaration takes one shader child, in order. `eval` and
`sample` both work.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const source = `
uniform shader img;
uniform float uShift;

half4 main(float2 pos) {
  half4 base = img.eval(pos);
  half4 red = img.eval(pos + float2(uShift, 0.0));
  half4 blue = sample(img, pos - float2(uShift, 0.0));
  return half4(red.r, base.g, blue.b, base.a);
}
`

<Shader source={source} uniforms={{ uShift: 4 }}>
  <ImageShader image={image} fit="cover" rect={{ x: 0, y: 0, width: 300, height: 200 }} />
</Shader>
```

</Tab>
<Tab value="Imperative">

```ts
const source = `
uniform shader img;
uniform float uShift;

half4 main(float2 pos) {
  half4 base = img.eval(pos);
  half4 red = img.eval(pos + float2(uShift, 0.0));
  half4 blue = sample(img, pos - float2(uShift, 0.0));
  return half4(red.r, base.g, blue.b, base.a);
}
`

shader({ source, uniforms: { uShift: 4 } }, [
  imageShader({ image, fit: 'cover', rect: { x: 0, y: 0, width: 300, height: 200 } }),
])
```

</Tab>
</Tabs>

Any shader works as an input, not just images:

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
<Shader source={banded}>
  <LinearGradient start={{ x: 0, y: 0 }} end={{ x: 300, y: 0 }} colors={['#2b6cff', '#ff3b6b']} />
</Shader>
```

</Tab>
<Tab value="Imperative">

```ts
shader({ source: banded }, [
  linearGradient({ start: { x: 0, y: 0 }, end: { x: 300, y: 0 }, colors: ['#2b6cff', '#ff3b6b'] }),
])
```

</Tab>
</Tabs>

A count mismatch throws while the scene is compiled on commit:

```
[tgfx] shader: the source declares 1 'uniform shader' (img) but 0 shader children
were given — pass one shader child per declaration, in order
```

## Filtering what is already drawn

`<Shader>` is a paint *source*: it decides the colour of the pixels a shape is
about to fill, and knows nothing about what is behind it.
[`RuntimeShader`](/api/variables/RuntimeShader) is the other half — it runs over
pixels that have already been drawn
([`RuntimeShaderProps`](/api/interfaces/RuntimeShaderProps)). The source
declares exactly one `uniform shader` for that drawing and samples it the usual
way, with coordinates in the drawing's own pixels:

```tsx
import { Canvas, Circle, Group, Rect, RuntimeShader } from 'react-native-tgfx'

const swapChannels = `
uniform shader content;
half4 main(float2 p) {
  half4 c = content.eval(p);
  return half4(c.b, c.g, c.r, c.a);
}
`

<Canvas style={{ width: 300, height: 140 }}>
  <Group>
    <RuntimeShader source={swapChannels} inputName="content" />
    <Rect x={0} y={0} width={150} height={140} color="#d94f4f" />
    <Circle cx={200} cy={70} r={50} color="#4f7fd9" />
  </Group>
</Canvas>
```

Inside a `<Group>` the shader sees **everything the group drew, composited
once** — both the rect and the circle above, as a single image. That is what
makes a second pass possible: nest a group per pass and each one filters the
result of the one inside it.

```tsx
// Blur first, then posterize what the blur produced.
<Group>
  <RuntimeShader source={posterize} inputName="content" />
  <Group>
    <RuntimeShader source={blurish} inputName="content" sampleRadiusPx={4} />
    <Rect x={0} y={0} width={300} height={140} color="#d94f4f" />
  </Group>
</Group>
```

A group takes one `<RuntimeShader>`; two would have nothing meaningful to
compose, so it throws and points you at nesting. On a shape instead of a group
it joins the filter chain beside `<Blur>` and `<DropShadow>`, filtering that one
draw, in declaration order:

```tsx
<Circle cx={70} cy={70} r={50} color="#4f7fd9">
  <Blur blur={4} />
  <RuntimeShader source={posterize} inputName="content" />
</Circle>
```

### Sampling neighbours

A shader that reads pixels other than the one it is producing — a blur, an edge
detector, anything with a kernel — must say how far it reaches, in drawing
pixels:

```tsx
<RuntimeShader
  source={edges}
  inputName="content"
  sampleRadiusPx={3}
  tileMode="clamp"
/>
```

`sampleRadiusPx` does not change the size of the result. It tells the renderer
to keep that much extra drawing around the edges, so a pixel on the boundary has
real neighbours to read instead of nothing. `tileMode` decides what a sample
past the edge of the drawing sees: `clamp` (the default) repeats the edge pixel,
`decal` returns transparent, and `repeat`/`mirror` wrap.

### Uniforms

Uniforms work exactly as they do on `<Shader>` — a `SharedValue` component
animates from a value slot with no JavaScript per frame — with one restriction:
every declared uniform must be a float scalar or vector (`float`, `float2`,
`float3`, `float4`) and must be supplied. An `int` or matrix uniform has no
value slots, so it is rejected rather than silently frozen.

```tsx
const progress = useSharedValue(0)

<Group>
  <RuntimeShader
    source={fade}
    inputName="content"
    uniforms={{ uProgress: progress }}
  />
  <Rect x={0} y={0} width={300} height={140} color="#d94f4f" />
</Group>
```

A changed uniform rebuilds the filter natively, which is cheaper than a scene
re-encode but not free: the compiled shader program is cached and reused, and a
slot whose value has not actually moved keeps the existing filter untouched.
