[`Image`](/api/functions/Image) takes a `require()`d asset, URL, file path, SVG
markup or base64:

```tsx
import { Canvas, Image } from 'react-native-tgfx'

<Canvas style={{ width: 300, height: 400 }}>
  <Image source={require('./cat.png')} x={0} y={0} width={300} height={200} fit="cover" />
  <Image source="https://picsum.photos/300/200" x={0} y={200} width={300} height={200} />
</Canvas>
```

For hundreds of animated nodes, [`TgfxImage`](/api/variables/TgfxImage) is
faster. It takes a loaded handle:

```tsx
import { Canvas, TgfxImage, useImage } from 'react-native-tgfx'

const photo = useImage(require('./cat.png'))

photo != null && (
  <TgfxImage image={photo} x={0} y={0} width={300} height={200} fit="cover" />
)
```

</Tab>
<Tab value="Imperative">

```ts
import { image, loadImage } from 'react-native-tgfx'

const photo = await loadImage(require('./cat.png'))

scene.add(image({ image: photo, x: 0, y: 0, width: 300, height: 200, fit: 'cover' }))
```

</Tab>
</Tabs>

[`useImage`](/api/functions/useImage) returns [`TgfxImage`](/api/interfaces/TgfxImage) or `null`.
[`useImageState`](/api/functions/useImageState) returns [`ImageState`](/api/interfaces/ImageState) with `loading` and `error`.
[`loadImage`](/api/functions/loadImage) is the promise form.

[`ImageProps`](/api/interfaces/ImageProps) · [`Fit`](/api/type-aliases/Fit) · [`Sampling`](/api/type-aliases/Sampling)

In Android release builds, asset names can't differ only by extension
(`logo.png`, `logo.webp`).

## SVG documents

A whole SVG document draws with [`ImageSVG`](/api/variables/ImageSVG):

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
import { Canvas, ImageSVG, useImage } from 'react-native-tgfx'

const icon = useImage(require('./logo.svg'))
const dot = useImage('<svg viewBox="0 0 24 24"><circle cx="12" cy="12" r="10" fill="#0a84ff"/></svg>')

<ImageSVG image={icon} x={0} y={0} width={96} height={96} />
<ImageSVG image={dot} x={104} y={0} width={96} height={96} />
```

</Tab>
<Tab value="Imperative">

```ts
import { imageSvg, loadImage } from 'react-native-tgfx'

const icon = await loadImage(require('./logo.svg'))
const dot = await loadImage('<svg viewBox="0 0 24 24"><circle cx="12" cy="12" r="10" fill="#0a84ff"/></svg>')

scene.add(imageSvg({ image: icon, x: 0, y: 0, width: 96, height: 96 }))
scene.add(imageSvg({ image: dot, x: 104, y: 0, width: 96, height: 96 }))
```

</Tab>
</Tabs>

`<ImageSVG>` is `<TgfxImage>` under a Skia-compatible name. It is redrawn at
any size. Use `<Path>` for a single `d` string.

[`ImageSVGProps`](/api/interfaces/ImageSVGProps)

## Colour profiles

Embedded ICC profiles are honoured: images are converted into the canvas's
colour space. An sRGB canvas clips out-of-gamut colour. A
[`colorSpace="display-p3"` canvas](/api/interfaces/CanvasProps) keeps it.

Images with no readable profile are read as sRGB.

<Callout type="warn">
  On iOS, PNG and JPEG decode to sRGB, so a P3 canvas cannot recover
  wide-gamut colour.
</Callout>

## Derived images

These reuse the decoded source.

```ts
const thumb = photo.scaled(200, 200)
const sprite = sheet.subset(0, 0, 64, 64)
const upright = photo.oriented('rightTop')
const frosted = photo.blurred(20, 20)
```

`oriented` takes an EXIF [`Orientation`](/api/type-aliases/Orientation).

[`useDerivedImage`](/api/functions/useDerivedImage) is the hook form ([`Derivation`](/api/type-aliases/Derivation)).

```tsx
const thumb = useDerivedImage(photo, { type: 'scaled', width: 200, height: 200 })
```

## Encode and save

Any image handle encodes to bytes or saves to disk:

```ts
const bytes = await image.encode('webp', 90)   // zero-copy ArrayBuffer, for upload
await image.save(`${dir}/thumb.jpg`, 'jpeg', 85) // written natively; bytes never enter JS
```

`format` is `'png'` (default), `'jpeg'`, `'webp'` or `'raw'` (straight-alpha
RGBA). Disposed handles and live camera or video frames reject.

## Native buffers

[`imageFromNativeBuffer`](/api/functions/imageFromNativeBuffer) wraps a camera or
decoder buffer without a copy ([`PixelFormat`](/api/type-aliases/PixelFormat)).
Release the producer's buffer after wrapping, or use
[`useCameraFrame`](/api/functions/useCameraFrame).

```tsx
let frameImage: TgfxImage
const buffer = frame.getNativeBuffer()
try {
  frameImage = imageFromNativeBuffer(buffer.pointer, 'bt601-limited')
} finally {
  buffer.release()
  frame.dispose()
}

// Draw with frameImage, then dispose it when the stream ends.
```

## Decoded pixels

[`imageFromPixels`](/api/functions/imageFromPixels) wraps premultiplied RGBA,
such as an ML model's output. `rowBytes` (a multiple of 4) defaults to tightly
packed.

```tsx
const image = imageFromPixels(pixels, width, height)
```

A buffer from another native module is borrowed, so don't write to it while the
handle uses it. A JS `ArrayBuffer` is copied.

`subset`, `scaled`, `oriented`, `blurred`, `encode` and `save` throw on these
handles.

For a stream, reuse one handle with
[`setPixels`](/api/interfaces/TgfxImage#setpixels):

```tsx
if (image != null) {
  image.setPixels(pixels, width, height)
} else {
  image = imageFromPixels(pixels, width, height)
}
```

## Cache

```tsx
setImageCacheLimit(32 * 1024 * 1024)
```

The default is 64 MB of decoded pixels. A canvas's GPU cache uses the same
limit when it is above 256 MB, and 256 MB otherwise.

[`getCacheInfo`](/api/functions/getCacheInfo) reports usage.
[`purgeCaches`](/api/functions/purgeCaches) frees it all, e.g. on memory pressure:

```tsx
const { imageBytes, imageLimit, gpuBytes, offscreenGpuBytes } = getCacheInfo()

purgeCaches()
```

Handles stay valid. Read `gpuBytes` a frame after purging.

## Video

[`useVideo`](/api/functions/useVideo) returns a [`Video`](/api/interfaces/Video)
whose `currentFrame` goes straight to `<TgfxImage>`. It needs Reanimated and
Worklets. [`loadVideo`](/api/functions/loadVideo) returns the raw native player
instead, so call `updateFrame()` and `release()` yourself.

Its options are a [`VideoOptions`](/api/interfaces/VideoOptions):

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
useVideo(require('./clip.mp4'), {
  seek: 1500,     // jump to 1.5s; seeks again whenever this changes
  paused: false,  // plays as soon as it's open (the default)
  looping: true,
  volume: 0.5,    // 0 to 1, defaults to 0 - a canvas video is usually decoration
})
```

</Tab>
<Tab value="Imperative">

```ts
const player = await createVideoPlayer(require('./clip.mp4'), {
  seek: 1500,     // jump to 1.5s; seeks again whenever this changes
  paused: false,  // plays as soon as it's open (the default)
  looping: true,
  volume: 0.5,    // 0 to 1, defaults to 0 - a canvas video is usually decoration
})

// currentFrame is a one-time snapshot at add time - build the node per frame:
player.onFrame((frame) =>
  scene.add(image({ image: frame, x: 0, y: 0, width: 1280, height: 720 }))
)
```

</Tab>
</Tabs>
